# patsissons/tap

Homebrew formulae and casks for tools by [@patsissons](https://github.com/patsissons).

```sh
brew install patsissons/tap/<formula>
brew install --cask patsissons/tap/<cask>
```

or tap once and install by name:

```sh
brew tap patsissons/tap
brew install <formula>
brew install --cask <cask>
```

## Formulae

| Formula | Description |
|---|---|
| [macbat](https://macbat.lgtm.page) | Sudoless power monitor TUI for Apple Silicon laptops |

## Casks

| Cask | Description |
|---|---|
| [unsleep](https://unsleep.lgtm.page) | Menu bar app and CLI that keeps your Mac awake, even with the lid closed |
